# Moon Phase

Moon phase tracker. Works offline.

- **iPhone:** open the web page in Safari, tap Share, then Add to Home Screen.
- **Android:** download `HighlanderMoon.apk` from the latest release and install it.

The app is one page in `web/`. The Android app in `android/` bundles the same files.
Pushing to `main` publishes the web page. The APK builds only when the workflow is run by hand (Settings, Pages, Source: GitHub Actions).
